# FIFA26-Agent 可观测体系方案

> 生成日期: 2026-06-02  
> 当前可观测状态: **最小化**（仅 Fastify 默认日志，无结构化、无指标、无告警）  
> 目标: 用轻量方案覆盖「日志 + 指标 + 告警」三支柱，不引入重型基础设施

---

## 一、现状评估

| 维度 | 当前状态 | 问题 |
|------|---------|------|
| 访问日志 | Fastify 默认 pino 输出 | JSON 但无请求耗时/状态码字段规范化 |
| 应用日志 | `console.log` / 无统一格式 | 无 level 区分，生产难以过滤 |
| AI 调用日志 | 无 | Kimi 调用耗时、token 用量完全黑盒 |
| Firo API 日志 | 无 | 签名失败、超时静默 |
| 性能指标 | 无 | 无法判断哪个端点慢 |
| 错误聚合 | 无 | 报错只在本地 stderr |
| 健康检查 | `/health` 存在 | 只返回配置状态，无依赖健康探针 |

## 三、日志体系（Logs）

### 3.1 结构化日志规范

所有日志统一 JSON 格式，包含以下字段：

```typescript
interface LogEntry {
  level: 'debug' | 'info' | 'warn' | 'error';
  time: number;          // Unix ms
  module: string;        // 'firo' | 'ai' | 'routes' | 'ingest'
  event: string;         // 事件名，snake_case
  durationMs?: number;   // 耗时（外部调用必填）
  matchId?: number;      // 关联比赛 ID
  error?: string;        // 错误信息
  [key: string]: unknown;
}
```

### 3.2 日志模块实现

**文件**: `server/src/observability/logger.ts`

```typescript
import pino from 'pino';

export const logger = pino({
  level: process.env.LOG_LEVEL ?? 'info',
  transport: process.env.NODE_ENV === 'development'
    ? { target: 'pino-pretty', options: { colorize: true } }
    : undefined,
});

// 各模块子 logger（自动带 module 字段）
export const firoLogger = logger.child({ module: 'firo' });
export const aiLogger   = logger.child({ module: 'ai' });
export const routeLogger = logger.child({ module: 'routes' });
```

### 3.3 关键埋点位置

#### Firo API 调用（`firoApi.ts`）

```typescript
// 每次 firoGet 调用记录
firoLogger.info({ event: 'firo_request', path, durationMs });
firoLogger.error({ event: 'firo_error', path, error: e.message });
```

#### AI 分析调用（`lotteryAnalysis.ts`）

```typescript
aiLogger.info({
  event: 'ai_analysis_start',
  matchId,
  model: 'kimi-k2.6',
});
aiLogger.info({
  event: 'ai_analysis_done',
  matchId,
  durationMs,
  inputTokens,
  outputTokens,
  confidence: result.confidence,
});
aiLogger.warn({ event: 'ai_analysis_fallback', matchId, reason });
```

#### 路由请求（全局 hook）

```typescript
// Fastify onRequest + onResponse hooks
server.addHook('onResponse', (request, reply, done) => {
  routeLogger.info({
    event: 'http_request',
    method: request.method,
    url: request.url,
    statusCode: reply.statusCode,
    durationMs: reply.elapsedTime,
  });
  done();
});
```

## 四、指标体系（Metrics）

### 4.1 核心指标定义

不引入 Prometheus，使用内存计数器 + `/api/metrics` 端点输出：

**文件**: `server/src/observability/metrics.ts`

```typescript
interface Metrics {
  // 请求计数
  http_requests_total: Record<string, number>;    // key: "GET /api/lottery/matches:200"
  http_errors_total: number;

  // 外部 API
  firo_requests_total: number;
  firo_errors_total: number;
  firo_avg_duration_ms: number;

  // AI 分析
  ai_analysis_total: number;
  ai_analysis_errors: number;
  ai_tokens_used_total: number;
  ai_avg_duration_ms: number;

  // 竞彩业务
  lottery_matches_served: number;   // 今日已服务场次数
  ai_cache_hits: number;            // 分析缓存命中次数（实现缓存后）

  // 系统
  uptime_seconds: number;
  memory_rss_mb: number;
}
```

### 4.3 关键业务指标看板（文字版）

日常需要关注的5个核心数字：

| 指标 | 正常范围 | 告警阈值 |
|------|---------|---------|
| Firo API 错误率 | < 2% | > 10% |
| AI 分析平均耗时 | < 8s | > 15s |
| API 响应 P99 | < 500ms | > 2000ms |
| AI Token 日用量 | < 100K | > 200K（成本控制）|
| 内存 RSS | < 200MB | > 500MB |

## 五、错误追踪

### 5.1 轻量方案：结构化错误日志 + 本地聚合

不需要 Sentry，利用 pino 日志聚合：

```typescript
// server/src/observability/errorTracker.ts
export function trackError(err: Error, context: Record<string, unknown> = {}) {
  logger.error({
    event: 'unhandled_error',
    error: err.message,
    stack: err.stack,
    ...context,
  });
  metrics.http_errors_total++;
}

// Fastify 全局错误 hook
server.setErrorHandler((error, request, reply) => {
  trackError(error, { url: request.url, method: request.method });
  reply.status(500).send({ error: 'Internal Server Error' });
});
```

### 5.2 进阶：飞书/邮件告警（可选）

当错误率超阈值时，发送简单通知：

```typescript
// 每分钟检查一次，错误率 > 10% 发飞书 webhook
async function checkAndAlert() {
  const errorRate = metrics.firo_errors_total / metrics.firo_requests_total;
  if (errorRate > 0.1) {
    await fetch(process.env.FEISHU_WEBHOOK_URL!, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        msg_type: 'text',
        content: { text: `⚠️ FIFA26-Agent Firo API 错误率: ${(errorRate * 100).toFixed(1)}%` },
      }),
    });
  }
}
setInterval(checkAndAlert, 60_000);
```

## 七、前端可观测

### 7.1 关键用户行为埋点

```javascript
// src/observability/analytics.js
function track(event, props = {}) {
  // 开发环境打印，生产可对接统计平台
  if (import.meta.env.DEV) {
    console.debug('[track]', event, props);
    return;
  }
  // 可对接: 友盟/百度统计/自建埋点
  fetch('/api/track', {
    method: 'POST',
    body: JSON.stringify({ event, ...props, ts: Date.now() }),
  });
}

// 关键埋点位置
track('lottery_detail_view', { matchId });
track('ai_analysis_triggered', { matchId });
track('odds_tab_switch', { tab: 'HHAD' });
```

### 7.2 前端错误捕获

```javascript
// main.jsx
window.addEventListener('unhandledrejection', (e) => {

  // 可上报到后端: POST /api/client-error
});

window.onerror = (msg, src, line) => {
  console.error('[window error]', { msg, src, line });
};
```
