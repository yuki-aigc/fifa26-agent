## 二、可迭代功能点（按优先级）

### P0 — 核心体验完善（强烈建议）

#### 2.1 竞彩赔率自动刷新
**问题**: 当前进入详情后赔率静态，无法感知变化。  
**方案**: 详情页加「刷新」按钮 or 每60秒轮询一次 `/api/lottery/matches/:id`，赔率有变化则高亮闪动。  
**工作量**: 前端约2小时

#### 2.2 半全场/总进球/比分 赔率历史展示
**问题**: `hafuOddsList` / `ttgOddsList` / `crsOddsList` 已从 API 返回，但前端未展示。  
**方案**: 在详情页赔率走势区增加3个Tab (HAFU / TTG / CRS)，结构化类型定义。  
**工作量**: 前后端各约2小时

#### 2.3 AI 分析缓存
**问题**: 每次点击「AI分析」都调 LLM，成本高且慢（约3-5秒）。  
**方案**: 服务端 Map/Redis 缓存 `matchId → analysisResult`，TTL 30分钟。  
**工作量**: 后端约1小时

---

### P1 — 功能扩展（近期可做）

#### 2.4 历史赛程查询（按日期）
**问题**: 当前竞彩只显示当日赛程，无法查昨日或明日。  
**方案**: 列表页顶部加日期选择器，调 `fetchLotteryAllList(date)`。  
**工作量**: 前后端各约1小时

#### 2.5 球员出场统计展示
**问题**: `FiroPlayer` 类型已完整定义(出场/首发/替补/进球/助攻)，前端无展示入口。  
**方案**: 在详情页「伤停名单」下方增加「主力阵容」折叠卡，按位置(GK/DEF/MID/FWD)分组。  
**工作量**: 前端约3小时

#### 2.6 竞彩收藏/关注
**问题**: 多场比赛时找不到关注场次。  
**方案**: 列表每行加⭐收藏，持久化到 localStorage，收藏场次置顶。  
**工作量**: 纯前端约2小时

#### 2.7 串关辅助工具
**问题**: 用户常用竞彩串关策略（2串1/3串1），需要组合赔率计算。  
**方案**: 详情页 AI 分析结果下方增加「串关计算器」，勾选多个场次玩法后自动计算盈亏比。  
**工作量**: 前端约4小时

#### 2.8 FIFA2026 积分榜前端页面
**问题**: 后端 `standings.ts` 已实现，前端无对应展示页。  
**方案**: 在「赛程」Tab 内增加积分榜 Tab 切换。  
**工作量**: 前端约3小时

### P2 — 体验提升（可延后）

#### 2.9 暗色模式
**方案**: CSS variables 支持 `prefers-color-scheme`，暖棕色系 → 深棕/灰黑。

#### 2.10 赛前推送提醒
**方案**: 用户收藏场次后，比赛开始前1小时通过 Web Push 或微信服务号提醒。  
**依赖**: 需要用户账号体系

#### 2.11 走势图可视化
**方案**: 赔率走势从文字表格升级为折线迷你图（recharts 或 canvas）。

#### 2.12 跨日期对比分析
**方案**: AI分析扩展为「赔率异动预警」——当赔率在1小时内变化超过阈值时主动标红提示。

---

### P3 — 平台扩展（中长期）

#### 2.13 用户账号与购彩记录追踪
**方案**: 用户登录后可记录自己的购彩结果，系统自动统计盈亏、准确率。

#### 2.14 多数据源赔率对比
**方案**: 除官方竞彩赔率外，接入亚盘/欧赔等参考线，在详情页做对比展示。

#### 2.15 微信小程序/公众号版本
**方案**: H5 已可嵌入微信 WebView，主要工作是接入微信JS-SDK做分享和支付。

## 三、技术债与优化点

| 项目 | 优先级 | 说明 |
|------|--------|------|
| `FiroOddsHistory` 半全场/总进球/比分字段结构化 | 中 | 当前为 `unknown[]`，需要补充类型定义 |
| 赔率走势赔率展示 flag 未应用在列表页 | 低 | 列表 `OddsCell` 缺 flag 参数来源 |
| 竞彩 Tab 初始状态 bug | 低 | App.jsx `useState('matches')` 默认不是竞彩Tab |
| 后端无请求日志中间件 | 低 | 添加 `fastify-log-request` 利于调试 |
| SQLite WAL 文件清理 | 低 | `fifa26.sqlite-shm/wal` 可定期 CHECKPOINT |

## 五、API 端点总览

```
GET /health                              # 系统健康 + AI配置
GET /api/teams                           # FIFA球队列表
GET /api/teams/:code                     # 球队详情
GET /api/players                         # 球员列表
GET /api/players/:id                     # 球员详情
GET /api/matches                         # 比赛列表
GET /api/matches/:id                     # 比赛详情
GET /api/matches/:id/prediction?ai=1     # 比赛AI预测
GET /api/accuracy                        # 预测准确率
GET /api/lottery/matches                 # 竞彩当日赛程
GET /api/lottery/matches/:id             # 单场情报(H2H+赔率历史)
GET /api/lottery/matches/:id/analysis    # 竞彩AI分析
```
